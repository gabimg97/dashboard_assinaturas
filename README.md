Dashboard de Vendas de Assinaturas Xbox

Sobre o projeto

Este projeto consiste na criação de um dashboard para análise de vendas de assinaturas do Xbox, utilizando dados referentes ao período de 1º de janeiro a 31 de dezembro de 2024. O objetivo é organizar as informações e facilitar a visualização dos resultados, contribuindo para a análise do faturamento e do comportamento das assinaturas.

Base de dados

A base de dados contém 295 registros de assinaturas e informações como:

Identificação e nome do cliente;

Plano contratado: Core, Standard ou Ultimate;

Data de início da assinatura;

Tipo de assinatura: mensal, trimestral ou anual;

Renovação automática;

Valores das assinaturas;

Adesão e valores adicionais do EA Play e do Minecraft;

Cupons de desconto;

Valor total da assinatura.

Desenvolvimento do projeto

O trabalho foi desenvolvido no Microsoft Excel, com organização da base de dados, utilização de tabelas dinâmicas e cálculos para responder às perguntas de negócio propostas. Também foi criada uma área de dashboard para apresentar as informações de forma visual e facilitar a interpretação dos resultados.

Perguntas de negócio

O projeto foi estruturado para investigar as seguintes questões:

Qual é o faturamento total das vendas de assinaturas anuais?

Como o faturamento das assinaturas se distribui entre clientes com e sem renovação automática?

Qual é o valor total das assinaturas adicionais do EA Play?

Qual é o valor total das assinaturas adicionais do Minecraft Season Pass?

As análises consideram os diferentes planos, tipos de assinatura e serviços adicionais presentes na base de dados.

Objetivo e aprendizado

O principal objetivo foi transformar dados tabulares em informações que facilitem a análise dos resultados comerciais. O projeto também permitiu praticar a organização de dados, a elaboração de cálculos, o uso de tabelas dinâmicas e a construção de visualizações para apoiar a tomada de decisões.

Ferramentas utilizadas

Microsoft Excel: organização dos dados, cálculos, tabelas dinâmicas e desenvolvimento do dashboard.
